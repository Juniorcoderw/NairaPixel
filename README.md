# NairaPixel

Mod cliente para **Minecraft Java 1.16.5 + Pixelmon 9.1.13**.

NairaPixel v1 se enfoca en un **Scanner automático**: al apuntar a un Pokémon, muestra información útil del ejemplar sin abrir menús ni ejecutar comandos.

## Scanner v1

- Nombre y nivel
- Tipo(s)
- Género
- Tamaño (Growth)
- IV total (%)
- 6 IV individuales
- Naturaleza
- Habilidad
- HA cuando corresponda
- Shiny / forma / paleta especial cuando corresponda
- Interfaz en español
- Firma visual: `by HJunior`

## Entorno objetivo

- Minecraft: 1.16.5
- Pixelmon: 9.1.13 Universal
- Forge: 36.2.34
- IDE recomendado: IntelliJ IDEA
